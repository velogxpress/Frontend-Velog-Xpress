VELOG XPRESS — DESIGN CONCEPT
============================

Open index.html in a browser to explore the public website.

Main prototype entry points:
- index.html: public homepage
- tracking.html: public parcel tracking experience
- auth.html: sign in, sign up, recovery and account states
- dashboard.html: full authenticated portal and complete page navigator

The dashboard prototype includes every route discovered in the current
frontend (64 existing routes, including equivalent/alias homepage routes).
Use “Toutes les pages” in the sidebar or search in the top bar to move between
public, authentication, administration, agent and customer screens.

This is a standalone design proposal. It does not call the production API and
does not modify the current Next.js application.
